WAR_POWERS - macOS
==================

Screens your whole-genome BAM for gene deletions/duplications by comparing each
gene's read depth to its flanking regions. Same tool as the Windows version, run
natively on your Mac - no WSL needed.

ONE-TIME SETUP
1) Install Homebrew (if needed). Open Terminal and paste:
     /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
2) Install samtools:
     brew install samtools

PUT YOUR FILES TOGETHER (one folder)
  - WAR_POWERS.command   (launcher)
  - WAR_POWERS.sh        (script)
  - genes_clean.txt      (gene list, one per line, editable)
  - your BAM             (any name; only ONE .bam in the folder)
The .bam.bai index is built automatically if missing.
BAM must be GRCh38/hg38 with NO "chr" prefix (e.g. "1", not "chr1").
Check:  samtools view -H yourfile.bam | grep '^@SQ' | head

RUN
  Double-click WAR_POWERS.command.
  First time, macOS may block it ("unidentified developer"). If so:
    right-click WAR_POWERS.command -> Open -> Open,  OR
    in Terminal:  xattr -d com.apple.quarantine WAR_POWERS.command WAR_POWERS.sh
  Prefer terminal?   cd /path/to/folder ;  bash WAR_POWERS.sh

OUTPUT
  deletion_all_data.tsv   every gene screened + a call
  deletion_hits.tsv       only flagged deletions

NOTE: Screening only, not clinical. Depth-based CNV calling has false
positives/negatives (especially in segmental-duplication regions). Confirm any
hit in IGV or with an orthogonal method.
